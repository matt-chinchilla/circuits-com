# Sponsor boards, tiers & board FX — full gotcha histories

Moved verbatim from CLAUDE.md 2026-08-28 to cut per-session context cost. The
compressed rule (same bold key) lives in CLAUDE.md's Gotchas section; this file
holds the full story — evidence, measurements, dates, refuted hypotheses.
**Update BOTH files when a rule changes.**

- **Sponsor tier↔placement matrix** — top-level cat (`parent_id IS NULL`) = **Platinum** only (single-slot); subcategory = **Gold** (single-slot) **+ Silver** (multi); keyword = Silver/Gold. "Featured" no longer exists (merged into Platinum). Enforced in THREE places that must agree: the Postgres trigger `sponsor_tier_placement_check` (catches raw SQL), `_validate_tier_placement`→422, and the admin `choosePlacement`. **Single-slot BLOCKS, it does not supersede**: `is_single_slot(tier, is_top_level)` — single home `app/models/sponsor.py`, imported by BOTH admin_sponsors and seed so the matrix cannot desync — gates `_reject_if_slot_taken`→409, and the incumbent (oldest active) keeps the slot. **The PATCH guard must ALSO fire on `status`→active**, or reactivating an Expired row into an occupied slot dodges a category/tier-only check and yields two active. Read-side picks OLDEST active (`created_at.asc`) to match. Migration 016's two partial unique indexes (`uq_active_{platinum,gold}_per_category`) are the un-bypassable DB backstop, and `seed.get_or_create_sponsor` is slot-aware so a reseed cannot crash them. Separately, `UNIQUE(supplier_id, category_id|keyword)` caps a supplier at one sponsorship per placement — a duplicate POST is a 409, not a second row.

- **SponsorBlock = the **Gold** subcategory flashlight PCB card** (`SponsorBlock.tsx`, `data-tier="gold"`). `touch-action: none` + `setPointerCapture` (skip on interactive descendants). NO `whileHover` (FM fires on touch). PCB SVG `preserveAspectRatio="xMidYMid meet"` (NOT `slice`; portrait viewBox `0 0 300 360`). `mask-composite` rim behind `@supports`. Float-in ONCE/session. **Flashlight is compositor-only (2026-06-21 rework, profiled 28→~21ms/frame @6×CPU)**: `.reveal` is a fixed 280px transform-WINDOW with a STATIC centred mask + a counter-translated `.revealInner` art holder (NOT a moving `mask-image at var(--mx)` — that re-rastered the full card ~8ms/frame); `.lamp` is a pre-baked gradient moved by `translate3d` (NO `mix-blend-mode` — the "deleted twice" anti-pattern); all positioned by DIRECT element transforms in a `place()` rAF (no cascading `--mx/--my` on the card → no subtree recalc). `will-change:transform` ONLY under `[data-lit]` — permanent will-change pins DPR³ GPU layers = iPhone OOM-reload.

- **Platinum `<canvas>` tile field (`csFx.tsx`) — the "alive" PCB**: a perpetual ~60fps `frame()` loop (ambient shimmer + cursor dome + click-flip) runs WHILE the board is on-screen — this IS the intended "alive" feel; **do NOT idle-pause it** (explicitly user-rejected 2026-06-21). The ONLY culling is its `IntersectionObserver` (+ `visibilitychange`), which pauses the loop OFF-screen only (verified rAF 60→0). **Deflate-on-release**: `clearCursor` sets `releaseAt` + `start()`; `frame()` ramps `domeStrength` 1→0 over `DEFLATE_MS` so all raised tiles descend together. **Mobile finger control**: `.csb.csbA` `touch-action:none` + `setPointerCapture` (onDown/onUp/onCancel in `useCsBoardFx`, guard interactive descendants) so a finger drives the dome without page-scroll (mirrors Gold). NEVER alter the visual consts (GAP 19 / shimmer .36 / dome R 72 / flip .34). Badge copy: Platinum `CsBadge`="Exclusive Partner", Gold kicker="◆ PREMIERE PARTNER" (2026-06-21; were "Category Sponsor"/"FEATURED PARTNER").

- **csFx canvas loop must NOT resurrect after unmount (2026-06-22 leak fix, commit dfd465d)** — a brand-takeover (`runWave` in `CategorySponsor` → deferred double-`requestAnimationFrame` → `field.wave()`) that FIRES AFTER the board unmounts restarted the perpetual ~60fps tile loop on a DETACHED canvas = one orphaned loop per interaction-then-nav → the site slows the more pages you visit (measured: 5 brand-takeovers → 6 loops / 360 rAF·s⁻¹ / heap 11→32MB). Fix: a `destroyed` flag in csFx set `true` in `destroy()` makes `start()`/`wave()` no-ops post-unmount — EVERY resurrection path (wave/setCursor/clearCursor/setEmblem) funnels through `start()`, so guarding it suffices; `wave()` also tracks its `setTimeout(120/600)` ids + clears them in `destroy()`. **Zero change to mounted/visible behavior** (the guard only intercepts calls that arrive after `destroy()`). Verified: 6 takeovers → 1 loop / 60 rAF·s⁻¹ / 11MB; a 36-nav all-page-type sweep → 0 leaked. **Profiling lesson: plain navigation was already CLEAN (per-component unmount works) — this leak ONLY surfaces via an INTERACTION-then-navigate probe (wrap `requestAnimationFrame` to count calls/sec = active loops × 60; trigger the interaction, navigate, count). A nav-only runtime test OR a static audit both UNDER-rate it; rate interaction-then-nav leaks by the interaction path, not the nav path.**

- **Sponsor boards, one source `sponsors`** — **Platinum** `CategorySponsor.tsx` = top-level via `GET /api/categories/{slug}/partners` → `platinum: SponsorResponse|null` (child→parent; `<canvas>` `csFx.tsx` 1:1 **never alter** GAP 19/shimmer .36/dome R 72/flip .34·255; GLOBAL `categorySponsor.scss`; `.cs-band` no gutter). **`csFx.snapshotCircuit` MUST strip `stroke-dash*` off the SVG clone** — the `.static .trace{dashoffset:0}` rule isn't in the serialized SVG → paths un-drawn → blank traces. `setEmblem` composites the open-slot upload icon into `pcb`; logos → **`CsLogo`/Gold `SbLogo` onError→lettermark**. **Gold** `SponsorBlock` (`category.sponsor`). **Silver** `SilverPartners.tsx` (`category.silver[]`, **first col 92px** desktop, **always U1–U5** w/ `SvSlotEmpty` "Advertise here"→`/contact`). `CategoryPartnersBanner.tsx` ALWAYS renders `<CategorySponsor>` (**Open-Placement when null — only on UNSOLD cats**; seed Platinum→2 flagships, PROD all-15-sold→free a cat). - **Sponsor/supplier LOGO `<img src>` MUST go through `safeImageUrl` (`@shared/utils/url`), NOT `safeHttpUrl` (2026-06-22)** — `safeHttpUrl` REJECTS `data:` URLs, but a logo may BE a data-URL (uploads), so logos need `safeImageUrl`: allows http(s) + raster `data:image/(png|jpe?g|webp|gif|avif);base64`, rejects `javascript:`/`data:text/html`/`data:image/svg+xml`→`null`. Applied at **FOUR** sponsor-image render sites — Platinum `CsLogo`, Gold `SbLogo`, Silver `svp-markimg`, AND the **keyword profile hero `public/pages/keyword/index.tsx`** (the easy-to-miss 4th — it pre-dates the boards; grep ALL `<img` of `image_url`/`logo_url` when touching this). Write-boundary defense-in-depth too: `validate_optional_image_url` (`api/app/utils/image_url.py`, allowlist + 200KB cap) as a Pydantic `@field_validator` on `SupplierCreate/Update.logo_url` + `AdminSponsorCreate/Update.image_url` (422 on hostile/oversize) so a forgotten read-site guard can't leak stored content. Guards `frontend/src/shared/utils/url.test.ts` + `api/tests/test_image_url_validation.py`.

- **Logo crop + sponsor brand colors (migration 018)** — `LogoCropperModal`'s **geometry authority is the MEASURED `frameSize`** (clientWidth + ResizeObserver), NEVER the 320 const: CSS caps the frame on mobile and the crop must match what is visible. `Sponsor.brand_*` OVERRIDE the `Supplier.brand_*` fallback, and **`brand_takeover` (true ONLY for sponsor-level colors) must be stamped at BOTH construction sites** — `_sponsor_board_dict` AND the keyword route — or a sold board silently falls back to steel. A same-values refetch must not stomp the logo-pad toggle (primitive-dep effect `[sponsor?.id, sponsor?.brand_takeover]`). The sponsor form requires BOTH colors or NEITHER (half-set = takeover with a surprise default channel); the supplier form propagates its pair onto that supplier's ACTIVE Platinum sponsorships on save, or the sold board needs a second edit. **`safeHexColor` (`@shared/utils/color`) gates EVERY stored-hex→inline-style path** (mirror of `safeImageUrl`), with `validate_optional_hex_color`→422 as the write-side half — both sides, or a bad value reaches an inline style. The demo pitch stores the SMALL cropped data-URL in sessionStorage (quota); encode failure surfaces via the `.csb-croperr` aria-live node, never silently. Known cosmetic: ~100ms steel flash on cold load (async `/partners`).

- **Circle completion at Gold/Silver/keyword is gated on `isDataImage(src) && naturalWidth===naturalHeight` in `onLoad`** — NOT on data-URL-ness alone: pre-2026-07 uploads were aspect-preserving (rectangular data-URL wordmarks exist in the DB) and must keep letterbox rendering. New crops are always square → circle-clip class per site (`logoCropped`/`svp-markimg-cropped`/`logoFull`). Known heuristic limit: a legacy data-URL from a SQUARE source will circle-crop (corners clipped) — "my logo's corners got cut" reports trace here. Platinum always circle-clipped, but round 2 (`a995e18`) adds the same `onLoad` gate to `CsLogo` (it had `onError` only) driving a new `csbA-logoimg-flush` class, and ALL 4 sites' cropped classes now size FLUSH to their solid rim (`calc(100% - Npx)` + `object-fit: cover`; rims are INSET box-shadows that paint under the img, hence the calc; keyword's `.logoFull` needs its `max-width/height: 100%` lines — the base `.logo` caps at 80%); legacy letterboxed logos stay gated out identically. Admin thumbnails stay rounded-square.
