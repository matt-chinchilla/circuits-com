# Manufacturers + Leads CRM Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Admin-only Manufacturers directory (merged CSV+catalog) and Leads call-tracking CRM with outcome history, rep pages, and a Dashboard panel.

**Architecture:** Five new FK-isolated tables (migration 036) bridged to suppliers by one nullable column; canon-service single home for name normalization used by seed AND feed importer; leads privacy enforced by dedicated router + calendar-style demo read-gate + guard tests; frontend = sponsors-table pattern pages behind a centered route-switch, plus one dashboard panel.

**Tech Stack:** FastAPI/SQLAlchemy/Alembic/Postgres (SQLite tests), React 19 + SCSS Modules admin SPA.

**Spec:** docs/superpowers/specs/2026-08-20-leads-crm-design.md (decision record; detail authority = docs/design-briefs/leads-crm-synthesis-2026-08-20.md — schema §2.3, pipeline §5.3, file plan §5.2 are BINDING).

## Global Constraints

- Migration number **036**, `down_revision="035"`; own deploy, never with `--reseed`.
- NO new FK into {suppliers, users, categories, sponsors, parts, category_suppliers}; only bridge = `suppliers.manufacturer_id` (nullable, ON DELETE SET NULL, partial-unique).
- `manufacturer_id` must appear in NEITHER `supplier_to_dict` NOR `SupplierResponse`.
- Leads router = `/api/admin/leads` own file; demo refused on reads (`demo_account_no_leads`, calendar.py:130-167 pattern) AND the dashboard leads endpoint.
- Auto-merge = canon equality ONLY; slash-head/prefix → `manufacturer_merge_candidates`.
- Outcome hexes `#153f80 / #4d189e / #b91c1c` + word + glyph everywhere; never `#2563eb`+`#7c3aed`.
- `SEED_MANUFACTURERS`/`SEED_LEADS` in BOTH compose files, literal code-default mirrors (`"true"`), + passthrough test.
- All new admin frontend under `src/admin/` only. TS strict, no `_` prefixes; SCSS modules camelCase, no empty rules; entities for non-ASCII glyphs.
- `recorded_by` = free String(120) (sold_by precedent), never FK to users.
- Every dict endpoint hand-built; add NO `response_model=` in new routes.
- Tests: pytest via `~/.local/bin/pytest` from `api/`; frontend `npx tsc -b` + eslint + vitest.

### Task 1: Canon service

**Files:** Create `api/app/services/manufacturer_canon.py`, `api/tests/test_manufacturer_canon.py`

**Interfaces (Produces):**
- `canon(name: str) -> str` — canonical key
- `split_branch(company: str) -> tuple[str, str | None]` — ("Bisco Industries", "Bohemia") from "Bisco Industries (Bohemia)"
- `domain_of(url: str | None) -> str | None` — bare registrable host, lowercase, no www

Rules (synthesis R3, binding): NFKC + casefold; `&`/`+` → " and "; strip `.,'®™`; `-_/` → space; collapse whitespace; parenthetical KEPT unless it is (a) an acronym of the base words, (b) a repeat of a base word, or (c) in {manufacturing, mfg, group, holdings, the}; repeatable trailing legal-suffix fold over {inc, incorporated, corp, corporation, co, company, ltd, limited, llc, plc, gmbh, ag, sa, sas, srl, spa, bv, nv, kk, oy, ab, aps, pty, pvt} — NEVER folding {usa, us, na}.
